=== FORMATO DA FATURA ===

CATEGORIAS:
- Aparecem seguidas de dois pontos ':'
- Exemplo: "Take Away:", "Frutas e Legumes:", "Mercearia:"
- Cada produto pertence à categoria do último cabeçalho encontrado

PRODUTOS COM QUANTIDADE = 1:
Formato: (TAXA) NOME_PRODUTO PREÇO
Exemplo:
  "(B) LEITE MIMOSA 1L 0,89"
  → name: "LEITE MIMOSA 1L"
  → category: categoria atual
  → quantity: 1.0
  → unit_price: 0.89
  → total_price: 0.89

PRODUTOS COM QUANTIDADE ≠ 1:
Formato linha 1: (TAXA) NOME_PRODUTO
Formato linha 2: QUANTIDADE X PREÇO_UNITARIO PREÇO_TOTAL
Exemplo:
  "(A) COUVE BROCOLO"
  "0,770 X 2,59 1,99"
  → name: "COUVE BROCOLO"
  → category: categoria atual
  → quantity: 0.770
  → unit_price: 2.59
  → total_price: 1.99

Outro exemplo:
  "(B) CALDO VERDE 800GR CZ CNT"
  "2 X 2,49 4,98"
  → name: "CALDO VERDE 800GR CZ CNT"
  → category: "Take Away" (se o cabeçalho anterior era "Take Away:")
  → quantity: 2.0
  → unit_price: 2.49
  → total_price: 4.98

=== INSTRUÇÕES DE CONVERSÃO ===

QUANTIDADES:
- "0,770 X 2,59 1,99" → quantity: 0.770
- "2 X 2,49 4,98" → quantity: 2.0
- Se só há preço (sem X), então quantity: 1.0

PREÇOS:
- Converte vírgula para ponto: "2,59" → 2.59
- Remove símbolo euro: "0,89€" → 0.89
- Números decimais: "1,99" → 1.99

DATAS:
- "20/12/2024" → "2024-12-20"
- "20-12-2024" → "2024-12-20"
- Formato obrigatório: YYYY-MM-DD

=== IGNORAR ===

NUNCA incluir como produtos:
- Linhas com "POUPANCA", "POUPANÇA", "DESCONTO"
- Linhas com "TOTAL", "SUBTOTAL"
- Linhas só com números (totais de secção)
- Cabeçalhos e rodapés
- Informação fiscal

=== VALIDAÇÕES CRÍTICAS ===

Para CADA item:
1. quantity × unit_price = total_price (margem de erro: 0.01€)
2. Se a multiplicação não bater, corrige o total_price

Para a fatura completa:
3. Soma de todos os total_price = total da fatura
